# RíoControl IA

Prototipo web desarrollado por Luis Yamba para el Hackathon Innovasoft 2026, donde obtuvo el segundo lugar.

Este repositorio se publica como evidencia técnica, académica y de portafolio del desarrollo realizado. El proyecto integra Flutter Web, Firebase Authentication, Cloud Firestore, Firebase AI Logic, Gemini, OpenStreetMap, control de acceso por roles, dashboard ejecutivo, alertas preventivas y visualización territorial.
